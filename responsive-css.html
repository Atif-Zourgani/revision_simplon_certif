C5 — Des wireframes au rendu final

Le rapport de certification attend un lien explicite entre ce qui était prévu dans les wireframes et ce qui a été implémenté : même disposition de zones, mêmes enchaînements de pages, personnalisation graphique cohérente (couleurs, mise en page) choisie et justifiée, pas seulement "ça rend bien".

Flexbox d'abord, sans media query

Avec display: flex et flex-wrap, les éléments passent à la ligne tout seuls quand ils ne rentrent plus. À privilégier en premier : plus simple, couvre déjà beaucoup de cas (cartes, listes de prestations, de cours...).

.cards {
    display: flex;
    flex-wrap: wrap;       /* les cartes passent a la ligne si ca ne rentre plus */
    gap: 16px;
}

.card {
    flex: 1 1 220px;       /* grandit/retrecit, mais jamais sous 220px */
    padding: 24px;
    box-sizing: border-box;
}

Media queries, quand la structure doit changer

Flexbox ne suffit pas toujours : parfois on veut une vraie structure différente entre mobile et desktop (ex : un menu empilé qui devient horizontal). C'est le rôle de la media query.

.site-header {
    display: flex;
    flex-direction: column;   /* empile logo et menu par defaut (mobile) */
    gap: 8px;
}

@media (min-width: 768px) {
    .site-header {
        flex-direction: row;          /* cote a cote a partir de la tablette/desktop */
        justify-content: space-between;
    }
}
Dans quel ordre réfléchir ?

D'abord se demander si flexbox seul peut suffire (une liste d'éléments similaires). Si un vrai changement de structure est nécessaire (empilé → côte à côte), ajouter une media query par-dessus.

Images : s'adapter sans déformer

.hero-image {
    width: 100%;        /* s'adapte a la largeur de l'ecran */
    max-width: 1200px;  /* mais ne depasse jamais cette taille sur grand ecran */
    height: auto;       /* garde les proportions */
}

Comment tester

  • Cmd+Shift+M (Mac) ou Ctrl+Shift+M (Windows/Linux) pour le mode responsive des DevTools.
  • Testez plusieurs tailles précises, pas seulement en redimensionnant la fenêtre à la main.
  • Vérifiez en priorité les pages identifiées mobile-first dans votre cadrage (C1).
Piège fréquent

Ne tester que sur son propre écran d'ordinateur, sans jamais activer le mode responsive : certains problèmes (menu qui déborde, texte qui chevauche une image) ne sont visibles qu'en-dessous d'une certaine largeur.
